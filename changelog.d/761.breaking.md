- **Adaptive dosing scores its outcome metrics on the latent monitor value, and
  `PCT_TIME_IN_WINDOW` is renamed `PCT_READINGS_IN_WINDOW`** (#761, ferx-core
  [#946](https://github.com/FeRx-NLME/ferx-core/issues/946), ferx-core pin
  moved to `a8f5f056`). In `ferx_simulate_adaptive()`, `metrics$SIGNAL_MIN`,
  `SIGNAL_MAX`, `SIGNAL_MEAN` and the window metric are now computed from the
  noise-free monitor value, like `AUC_TARGET_ATTAINMENT`, not from the
  assay-noised reading the controller titrated on: assay error is not part of
  the patient's outcome. Results change for monitors with assay error
  (`with_assay_error = true`); latent `observe` monitors are unchanged. The
  window metric counts decision readings inside `target_window`, never elapsed
  time, so it is now `metrics$PCT_READINGS_IN_WINDOW`; `PCT_TIME_IN_WINDOW` is
  kept with the same values for this release only and will be removed. The
  `doses` and `decisions` tables gain a `LATENT` column next to `SIGNAL`: the
  noise-free value each reading was drawn from (equal to `SIGNAL` without assay
  error).
