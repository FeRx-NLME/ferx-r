- **Transit / inverse-Gaussian IOV docs follow ferx-core #1560** (#411): IOV and
  time-varying-covariate subjects of `one_cpt_transit`, `two_cpt_transit`,
  `one_cpt_ig` and `two_cpt_ig` now run analytic, so `?ferx_fit`'s
  `ode_reltol` / `ode_abstol` name the cases that still fall back to the ODE twin
  (flip-flop, SS or infusion doses, `TIME`-dependent parameters, 24 or more stacked
  IOV random effects). The `one_cpt_transit_iov` example no longer says it reroutes
  to the twin, and its model file now runs the covariance step: on the current
  engine the fit with standard errors takes about 0.3 s, against 2.5 s before.
