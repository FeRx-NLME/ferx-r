- **`ferx_update_model(fit, path)` writes the fitted model with its final
  estimates as initial values** (#678), NONMEM's `final.mod`: theta, omega,
  sigma and kappa inits take the fitted values, while bounds, `FIX`, `(sd)`
  scale, `block_omega` structure, whole-line comments and every other block stay as
  written. It is the engine's own edit, the one the searches write their
  `final.ferx` with, so a refit from the file starts at the fit's OFV.
  `ferx_save_fit(..., write_model = TRUE)` writes the same file next to the
  bundle as `<name>_final.ferx`.
