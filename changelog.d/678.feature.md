- **`ferx_update_model(fit, path)` writes the fitted model with its final
  estimates as initial values** (#678), NONMEM's `final.mod`: theta, omega,
  sigma, kappa, `block_sigma` and `[mixture]` override inits take the fitted
  values, while bounds, `FIX`, `(sd)` scale, block structure, comments and
  every other block stay as written. It builds on the engine's own edit, the
  one the searches write their `final.ferx` with, so a refit from the file
  starts at the fit's OFV. A theta level block (`theta NAME[...]`) takes one
  init for all its levels, so it is left as declared, with a warning.
  `ferx_save_fit(..., write_model = TRUE)` writes the same file next to the
  bundle as `<name>_final.ferx`.
