- **`ferx_simulate(fit = )`, `ferx_calc_npde()` and `ferx_simulate_adaptive(fit = )`
  on a `[mixture]` fit use the fitted per-class Omega and Sigma** (#672). Every
  class used to run at the model file's values, ignoring `fit$omega`,
  `fit$sigma` and `fit$mixture_overrides`, so a from-fit simulation or NPDE
  reference drew each class at its initial spread (on the `mixture_override`
  fixture, ETA_CL variance 0.086 against a fitted 0.018 in class 1). Each class
  is now rebuilt from the fitted base Omega/Sigma plus `fit$mixture_overrides`,
  as `ferx_simulate_with_uncertainty()` does. These three refuse, with
  `E_FIT_INPUT_MISSING`, a `[mixture]` fit with per-class overrides but no
  `fit$mixture_overrides` (a `.fitrx` bundle saved before #655) instead of
  simulating it at the model file's values; `ferx_predict(fit = )` and
  `ferx_predict_survival()`, whose output reads no class Omega/Sigma, still
  run on such a fit.
