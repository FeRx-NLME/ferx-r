- **`ferx_simulate(fit = )`, `ferx_calc_npde()`, `ferx_simulate_adaptive(fit = )`,
  `ferx_predict(fit = )` and `ferx_predict_survival()` on a `[mixture]` fit use
  the fitted per-class Omega and Sigma** (#672). Every class used to run at the
  model file's values, ignoring `fit$omega`, `fit$sigma` and
  `fit$mixture_overrides`, so a from-fit simulation or NPDE reference drew each
  class at its initial spread (on the `mixture_override` fixture, ETA_CL
  variance 0.086 against a fitted 0.018 in class 1). Each class is now rebuilt
  from the fitted base Omega/Sigma plus `fit$mixture_overrides`, as
  `ferx_simulate_with_uncertainty()` does. A `[mixture]` fit with per-class
  overrides but no `fit$mixture_overrides` (a `.fitrx` bundle saved before
  #655) is refused instead of simulated at the model file's values.
