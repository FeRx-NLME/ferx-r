- **Simulations of a `[mixture]` model carry each subject's drawn class as an
  integer `MIXNUM` column** (#670;
  [ferx-core #2372](https://github.com/FeRx-NLME/ferx-core/issues/2372),
  [#2442](https://github.com/FeRx-NLME/ferx-core/pull/2442)), in
  `ferx_simulate()`, `ferx_simulate_with_uncertainty()` and the `trajectories`
  of `ferx_simulate_adaptive()`. It is NONMEM's `$TABLE MIXNUM` under
  `$SIMULATION`: one class per subject and replicate, so a VPC can be split by
  class with `split(sim, sim$MIXNUM)`. Other models' frames are unchanged, with
  no `MIXNUM` column.
