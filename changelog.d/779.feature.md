- **`ferx_simulate_adaptive()` summarises the population, decomposes the
  variance and runs assay replicates** (#779,
  [ferx-core #946](https://github.com/FeRx-NLME/ferx-core/issues/946)).
  Every run now returns `summary_rows` (the mean and median of each outcome
  metric and of the monitor's latent signal at each decision, per parameter
  draw), `summary_bands` (their quantiles across draws, `"not_drawn"` for a
  run with one draw) and `prediction_intervals` (the quantiles pooled over
  every run). `summary_probs` sets the three quantiles, and
  `summary_thresholds = list(PCT_READINGS_IN_WINDOW = 0.8)` adds the fraction
  of runs at or above a threshold. A new `n_reps` argument reruns each patient
  `n_reps` times with the same eta and new IOV and assay noise; the `REP`
  column of `doses`, `decisions` and `metrics` numbers them, and `n_reps = 1`
  is the run without replicates, bit for bit. `decompose = TRUE` splits the
  variance of each metric into parameter-uncertainty, between-subject and
  within-subject layers (`variance_components`, `variance_skipped`), with a
  Monte Carlo SE for each; it needs `n_reps >= 2` and `n_sim >= 2`, otherwise
  the call is refused with `E_ADAPTIVE_OPTIONS`.
