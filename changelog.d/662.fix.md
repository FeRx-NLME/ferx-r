- `ferx_save_fit()`, and so `ferx_fit(output = ...)`, no longer needs an
  external `zip` program. It shelled out through `utils::zip()`, so on a Linux
  machine without Info-ZIP installed the save failed after the whole fit with
  "'zip' must be a non-empty character string"; the `.fitrx` bundle is now
  written by the package itself (#662).
