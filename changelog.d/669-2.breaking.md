- **`ferx_simulate()` refuses more `[mixture]` inputs** (#669;
  [ferx-core #2163](https://github.com/FeRx-NLME/ferx-core/issues/2163)), now
  that it simulates each class: propensity-score matching is refused with
  `E_PROPENSITY_INPUT`; parameters without per-class Omega/Sigma, or with
  per-class blocks of the wrong count or shape, with `E_PARAM_SHAPE`; a
  residual magnitude that reads `MIXNUM` and vanishes in one class with
  `E_RUV_MAGNITUDE_NONPOSITIVE`, naming the class; and the transit /
  inverse-Gaussian flip-flop refusal is checked in every class.
