- **`ferx_xpose()` works again on R older than 4.6.0 for fits with binary or
  time-to-event rows.** (#702) Its "left out ... sdtab rows" note called
  `messageCondition()`, which base R only gained in 4.6.0, so on earlier R the
  call stopped with `could not find function "messageCondition"` instead of
  returning the Xpose data. Gaussian-only fits were not affected.
