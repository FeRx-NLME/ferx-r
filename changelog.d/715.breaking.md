- **`imp_auto` / `impmap_auto` fits can land on different numbers at the same
  seed** (#715, [ferx-core #2687](https://github.com/FeRx-NLME/ferx-core/issues/2687)):
  the importance-sample count now rises only once the objective has settled or
  the averaging window is about to start, each rise is sized to the
  Monte-Carlo SE instead of always doubling, and the count halves again, down
  to the starting value, when the SE falls below half the target. A cold
  start's descent can no longer set it for the whole run. Set `imp_auto =
  FALSE` (or `impmap_auto = FALSE`) to keep a fixed count.
