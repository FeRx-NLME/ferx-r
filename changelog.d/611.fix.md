- **`ferx_covariance()` and `ferx_sir()` classify their replay's warnings the
  way `ferx_fit()` does** (#611): the engine's warnings from a post-hoc
  covariance or SIR run are classified by ferx-core's `classify_warning`
  instead of being stamped `warning` / `covariance` (or `sir`). A replayed
  "Covariance step failed ..." is now the same `critical` / `covariance_failed`
  row as the fit's own, so `ferx_get_warnings()` no longer lists it twice under
  two classes. When the fit's own step did not run (`covariance = FALSE`), a
  replay that fails now counts as critical in the warning tally and shows
  `(covariance_failed)` on `print()`'s STATUS line, where it used to show as a
  plain warning. `check_strictness()` is unaffected: it does not read severity.
  SIR messages were already classed `sir` / `warning` by the engine and are
  unchanged.
