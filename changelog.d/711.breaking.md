- **`.fitrx` bundles are now format version 2, read by ferx-core's loader**
  (#711, [ferx-core #2693](https://github.com/FeRx-NLME/ferx-core/issues/2693)):
  `ferx_load_fit()` builds the list with the converter `ferx_fit()` uses, so a
  loaded fit has the fields a fresh one has. A bundle written by an older ferx
  fails with a version error, and a fit from an older `.rds`, which carries no
  bundle, is refused by `ferx_save_fit()`: refit the model. There is no
  migration.
