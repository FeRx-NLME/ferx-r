- **Engine changes from ferx-core `b259dd10..3f87757e` that can refuse a model
  or change a fit's choices** (#681):

  - **A level block now refuses a combination of random effects it absorbs**
    ([ferx-core #1878](https://github.com/FeRx-NLME/ferx-core/issues/1878),
    [#2362](https://github.com/FeRx-NLME/ferx-core/pull/2362)). The span
    certificate measured each random effect alone, so a model such as
    `E0 = TVE0 + PLACEBO + ETA_E0 + (ETA_E0 - ETA_X)^2 * OCC`, where moving
    both random effects together shifts the prediction only by a constant the
    level takes up, was bound. The check is now joint over a subject's etas
    and an occasion's kappas, and the refusal names the partners
    (`` `ETA_E0`, moved together with `ETA_X` ``). A model that bound before
    can be refused now.
  - **`optimizer = "auto"` picks `nlopt_lbfgs` for time-to-event, binary and
    CTMM models** (`fit$optimizer_label` reads `"auto (nlopt_lbfgs)"`
    there), so their estimates can move
    ([ferx-core #2482](https://github.com/FeRx-NLME/ferx-core/pull/2482)).
