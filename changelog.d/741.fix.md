- **An explicit `optimizer = "bobyqa"` on a `[mixture]` model no longer warns
  that it "was replaced by BOBYQA"** (#741,
  [ferx-core #2852](https://github.com/FeRx-NLME/ferx-core/issues/2852)).
  BOBYQA is the optimizer the mixture path runs, so the request was honoured
  all along and only the warning was wrong. An explicit `trust_region` still
  runs under BOBYQA there and still says so, now naming it as a model file
  spells it (`trust_region`, not `TrustRegion`).
