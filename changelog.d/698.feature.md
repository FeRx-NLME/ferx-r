- **`ferx_simulate()` and `ferx_simulate_with_uncertainty()` return the
  parameters each subject was drawn with** (#698, ferx-core #2505): a
  per-subject table - the drawn etas, one `<kappa>_<occasion>` column per
  IOV kappa and occasion, the `[individual_parameters]`, the `[derived]` /
  `[output]` values, and `MIXNUM` on a `[mixture]` model - travels as
  `attr(sim, "parameters")` and is read with the new `ferx_sim_parameters()`.
  It has one row per `(DRAW, SIM, ID)` and joins back to the observation rows
  on those columns. Values are taken at each subject's first observation row
  (NONMEM's `$TABLE ... FIRSTONLY`); the table's `varying` attribute, repeated
  when it prints, names every column that changes within a subject. Steady-state
  AUC as `F * dose / CL`, for example, no longer needs `IPRED` integrated.
