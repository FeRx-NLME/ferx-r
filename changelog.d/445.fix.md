- **`ferx_model_get_section()` and `ferx_model_set_section()` address
  instance-named sections**
  ([#445](https://github.com/FeRx-NLME/ferx-r/issues/445)). Headers are now
  read with the engine's grammar, the one `ferx_model_validate()` uses since
  #306. An instance-named section is addressed as its header reads
  (`"event_model cause_a"`), and a bare type addresses the unnamed header of
  that type (`[event_model]`, also beside named instances of it) or, when
  there is none, the type's only instance (`"covariate_nn"`). A bare type
  with several instances and no unnamed header, such as `"event_model"` in
  `tte_competing_risks`, is refused with the instances to choose from, where
  it used to report the section missing. A duplicated header is refused
  rather than one copy picked. The type matches case-insensitively and the instance exactly, as in the engine.
  A `[0.01, 0.1]` row of a multi-line `block_omega` is no longer taken for a
  section header, and a header followed by a comment is recognised.
