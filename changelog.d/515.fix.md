- **`ferx_fit()` no longer warns about a `[fit_options]` "conflict" between two
  spellings of one value.** (#515) The check compared the model file's value
  with the call's as text, so a file `gradient = autodiff` against
  `gradient = "ad"`, `bloq_method = none` against `"drop"`, `method = [saem,
  imp]` against `c("saem", "imp")`, or `ode_reltol = 1e-4` against `0.0001`
  each warned that the call overrode the file. Both values are now read the way
  the engine reads them and compared after that, so only a real difference
  warns, with the same message as before. A value the engine refuses is still
  compared as text.
