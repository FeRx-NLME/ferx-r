- **A level block that scales the residual error as an `iiv_on_ruv` random
  effect does is now refused when binding** (#687,
  [ferx-core #1879](https://github.com/FeRx-NLME/ferx-core/issues/1879),
  [#2529](https://github.com/FeRx-NLME/ferx-core/pull/2529)), with a message
  naming the random effect. The check used to look only at the predictions,
  which that random effect never moves, so the model bound and the fit drove
  its omega to zero. A block on the prediction, or on only the additive part
  of a combined error, still binds; a nested `[STUDY, OCC]` residual block
  with `iiv_on_ruv` under `auto` now binds `sum_to_zero_within`.
