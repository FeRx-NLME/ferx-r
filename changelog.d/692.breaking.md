- **`ferx_simulate_adaptive()`: `$decisions$OUTCOME` can be `"not_due"`, and
  `$metrics$N_HOLDS` no longer counts those points** (#692,
  [ferx-core #945](https://github.com/FeRx-NLME/ferx-core/issues/945),
  [#2563](https://github.com/FeRx-NLME/ferx-core/pull/2563)). A model whose
  `[adaptive_dosing]` block declares a dosing interval logs each review-grid
  point at which no dose is due as `"not_due"` and counts it in the new
  `$metrics$N_NOT_DUE`; `N_HOLDS` counts only consulted decisions that gave no
  dose. Code that assumed `OUTCOME` is one of `"dosed"` / `"hold"` / `"stop"`
  needs the fourth value. Models without `intervals` are unchanged.
