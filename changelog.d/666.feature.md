- **A source tarball can now carry its Rust dependencies and build offline.**
  (#666) `tools/vendor-rust.sh` vendors every crate `src/rust/Cargo.lock`
  pins - ferx-core and ferx-tools at the pinned commit, plus the crates.io
  crates - into `src/rust/vendor.tar.xz`, which `R CMD build` then ships. A
  tarball built that way installs with no network and a read-only
  `CARGO_HOME`, as GxP validation rebuilds require. The vendored tarball is a
  release artifact and is not committed, so an install from GitHub still
  fetches the pinned ferx-core online, exactly as before. A new CI job
  installs the vendored tarball with networking disabled.
