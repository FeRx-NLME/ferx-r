- `?ferx_fit` (`threads`) and the README's Docker threads note now state the
  engine's default worker count correctly: the available cores minus one, but
  at least 2 when there are two or more cores (1 on a single core), at most 8.
  They said "floored at 1", so a 2-core machine or `docker run --cpus 2` was
  documented as getting 1 worker instead of 2 (#745).
