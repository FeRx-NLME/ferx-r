- **The package's Rust code runs on the mimalloc allocator** (#685) instead of the
  system allocator: an estimation allocates many small, short-lived buffers per subject
  per evaluation. On the bundled examples a fit (`ferx_fit(threads = 1)`) runs 2–5.5%
  fewer instructions (`warfarin_iov` −5.5%, `warfarin_ode` −4.5%, `two_cpt_oral_cov`
  −2.5%, `mm_oral` −2.0%, whole R process) with identical results. The `ferx`
  command-line tool has used it since ferx-core #2435.
