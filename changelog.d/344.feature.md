- **`ferx_model_from_dcm()` exports a fitted deep compartment model as a plain
  population PK model** (#344,
  [ferx-core #1331](https://github.com/FeRx-NLME/ferx-core/issues/1331)): each
  `[covariate_nn]` block becomes ordinary `[individual_parameters]` equations
  at the fitted weights, and every other theta / omega / sigma / kappa is
  written at the fit's estimate. The exported model predicts exactly what the
  fitted network does, bit for bit, and loads in a build without the `nn`
  feature, which can also run the export. `weights = "fixed_theta"` keeps each
  weight as a named `FIX` theta instead of a literal; `network_only = TRUE`
  keeps the model file's other values; `theta =` exports from a weight vector
  without a fit. A fit of a different model is refused.
