- **Line-oriented progress for scripts** (#677): `progress` on
  `ferx_bootstrap()` and on every search (`ferx_covsearch()`,
  `ferx_iivsearch()`, `ferx_ruvsearch()`, `ferx_iovsearch()`,
  `ferx_modelsearch()`, `ferx_globalsearch()`, `ferx_amd()`) now also takes
  `"lines"`: plain records on stdout, one per line and flushed as they happen,
  so a log viewer tailing a job's output sees the run move. `progress = TRUE`
  picks it on its own in a non-interactive session (`Rscript`), where it used
  to draw the bootstrap's bar or write the searches' step messages to stderr;
  interactive sessions keep those. The bootstrap prints one line per completed
  replicate (`bootstrap: replicate 3/200 done`), the searches one per step,
  layer or batch. One line per search candidate, and each replicate's OFV and
  status, need the engine to report them (ferx-core #2512).
