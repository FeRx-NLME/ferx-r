- **`ferx_model_validate()` reports informational findings as `info`** (#660):
  the glue no longer matches the engine's severity exhaustively, so it builds
  against ferx-core with `Severity::Info` (ferx-core #2427). An `info` row
  prints as `info` rather than `warning`, and a model whose only findings are
  informational reads `Result: VALID (with notes)` instead of
  `VALID (with warnings)`.
