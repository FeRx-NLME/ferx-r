- `fit$final_gradient_source` says what kind of gradient `fit$final_gradient`
  is: `"optimizer"`, or for a derivative-free fit (`bobyqa`) `"analytic"` when
  the model can use the exact outer gradient and `"finite_difference"` when it
  cannot. `NULL` exactly when `final_gradient` is. Both now travel in `.fitrx`
  bundles, which did not carry `final_gradient` before, so `ferx_runlog()` shows
  the gradient on a reloaded fit too (#684).
