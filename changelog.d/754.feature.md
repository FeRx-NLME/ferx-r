- **`ferx_vpc_tte()` draws the VPC of a repeated-events (RTTE) endpoint**
  (#754, [ferx-core #1886](https://github.com/FeRx-NLME/ferx-core/issues/1886)).
  On an endpoint declared `type = rtte` it used to be refused; it now returns a
  `ferx_vpc_rtte` object with three families of observed curves, each beside
  the replicate band: the mean cumulative function (`mcf`, `mcf_band`), the
  Kaplan-Meier curve of the time to the k-th event (`absolute`,
  `absolute_band`) and of the time from the (k-1)-th event to the k-th (`gap`,
  `gap_band`), with `orders` giving the subjects in each curve. The new
  `max_order` argument sets the highest order; unset, it is the largest order
  at least 10 observed subjects reached. The observed curves match
  `survival::survfit` row for row. `plot()` draws an MCF panel and the curves
  by order (`which`, `orders`). A subject whose last record is an event raises
  `W_VPC_RTTE_ENDS_ON_EVENT`, and `print()` says how to fix the data.
