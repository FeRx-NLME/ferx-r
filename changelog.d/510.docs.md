- **The README no longer calls RK45 the default ODE stepper** (#510). The
  engine default is `ode_method = "auto"`, which solves a linear `[odes]`
  system exactly and otherwise picks the stepper per integration segment, as
  `?ferx_fit` already said. `?ferx_fit` now also links ferx-core's "Letting
  ferx pick the stepper" section, and a test ties the defaults `?ferx_fit`
  documents for the ODE, inner-loop and SIR settings to the engine's own.
