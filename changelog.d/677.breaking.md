- `progress = TRUE` outside an interactive session (e.g. under `Rscript`) now
  means `progress = "lines"`: the bootstrap prints a line per replicate on
  stdout instead of a progress bar, and a search's per-step summary moves from
  stderr to stdout, joined by a line per candidate. Pass `progress = "bar"` for
  the previous output. The default, `progress = interactive()`, still prints
  nothing in a script (#677).
