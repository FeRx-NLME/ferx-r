- **A data.frame column holding a 1-d array is accepted** (#722): a column made
  with `$<-` or `dplyr::mutate()` from `tapply()` (a 1-d array, which
  `data.frame()` would have flattened) was refused as "cannot be written as
  CSV" by `ferx_fit()`, `ferx_model_validate()` and every other entry point
  that takes a data.frame. It is now written as the vector it holds; a matrix
  column is still refused.
