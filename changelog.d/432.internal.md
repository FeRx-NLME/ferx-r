- **The `simulation_warnings` attribute can only carry a ferx-core
  diagnostics bundle and the glue's own occasion notes**
  ([#432](https://github.com/FeRx-NLME/ferx-r/issues/432)). The glue helper
  that attaches it takes the engine's `*_diag` result itself (through a
  `CoreDiag` trait on `SimulationOutput`, `PredictionOutput`,
  `SurvivalPredictionOutput` and `AdaptiveSimulationResult`) and an
  `OccasionNotes` value that only the occasion-deriving functions can build,
  rather than plain character vectors, so relaying the data reader's raw
  warnings - the #426 regression - no longer compiles through either
  argument. No change to what any call returns.
