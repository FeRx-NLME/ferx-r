- **`ferx_sim_parameters()` column names are unique** (#764): an eta,
  individual parameter or `[derived]` column spelled like a key (`DRAW`,
  `SIM`, `ID`), or an individual parameter spelled like a kappa column
  (`KAPPA_CL_1`), no longer gives a second column of that name - it is
  renamed `<name>.1`, as `make.unique()` would, and `attr(, "varying")` names
  the renamed column. Before, `merge(sim, params, by = c("DRAW", "SIM", "ID"))`
  could join on the model's column instead of the key.
