- **`ferx_sim_parameters()` column names are unique** (#764): a random
  effect, individual parameter or `[derived]` column spelled like a key
  (`DRAW`, `SIM`, `ID`) or a kappa column (`KAPPA_CL_1`) no longer gives a
  second column of that name - it gets a `make.unique()`-style suffix
  (`<name>.1`), the key or kappa column keeps its name, and
  `attr(, "varying")` names the renamed column. Before,
  `merge(sim, params, by = c("DRAW", "SIM", "ID"))` could join on the
  model's column instead of the key, and `params$KAPPA_CL_1` could return an
  eta.
