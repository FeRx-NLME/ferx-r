- **`ferx_fit(method = ...)` accepts exactly the engine's tokens and aliases**
  (#506), as a model file's `[fit_options] method` line does. Prefix
  abbreviations that R's `match.arg()` used to complete (`"sa"` for `"saem"`,
  `"lap"` for `"laplace"`) and the separator-less spellings
  `"importancesampling"` / `"importancesamplingmap"` are now refused with the
  engine's "unknown estimation method" error; write the method in full.
