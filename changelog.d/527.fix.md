- **`ferx_covariance()` and `ferx_sir()` run on the fit's thread width, and
  report the width they ran on.** (#527) Both used to run on the engine's
  default width (every core) whatever the fit was pinned to, while still
  reporting the fit's `n_threads_used`. They now take a `threads` argument:
  `NULL` (the default) uses `fit$n_threads_used`, `0` the engine default, and
  a positive integer pins the width. The returned fit's `n_threads_used` is
  the width the step ran on. Results do not depend on the width.
