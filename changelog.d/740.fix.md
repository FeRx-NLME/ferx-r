- **`gn_lambda` is deprecated: setting it now warns** (#740, ferx-core #1841,
  #2828). It never had an effect: Gauss-Newton has used a trust region, not
  Levenberg-Marquardt damping, since ferx 0.1.0. The setting is still
  accepted, on every method, with a warning; the next minor release rejects
  it. `?ferx_fit` and `ex_optimizer_tuning.R` no longer offer it, and the
  Gauss-Newton trace now says what its `lm_lambda` column holds, the trust
  radius: `?ferx_trace` describes it, `plot()` of a GN fit labels the panel
  "Trust radius", and the run-log iteration table heads it `TR_RADIUS`. The
  trace column keeps the name `lm_lambda`.
