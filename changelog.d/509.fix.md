- **An explicit `optimizer_trace`, `scale_params` or `inits_from_nca`
  argument now wins over both `settings` and the model file** (#509). Given
  both as an argument and in `settings`, `optimizer_trace` and `scale_params`
  failed with "`settings` must be a uniquely-named list"; now the argument is
  used. An explicit `FALSE` is also sent to the engine, so it turns off a
  model file's `[fit_options] optimizer_trace = true` (or `scale_params`,
  `inits_from_nca`) instead of leaving it on. Left at its default, the
  argument sends nothing and a `settings` or model-file value is used.
