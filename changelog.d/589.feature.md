- **`inner_screen` setting** ([#589](https://github.com/FeRx-NLME/ferx-r/issues/589)).
  `ferx_fit(settings = list(inner_screen = 200L))` sets the size of the
  Sobol screen in the cold inner multi-start (default 100;
  `inner_screen = 0L` turns it off), as
  `[fit_options] inner_screen` does in a model file. `fit$scoring_settings`
  and `fit$sir_settings$scoring` record it, `ferx_covariance()` /
  `ferx_sir()` re-score under it, and `ferx_save_fit()` / `ferx_load_fit()`
  keep it. A fit or `.fitrx` bundle saved before the setting existed reads it
  as `0`, the screen that fit did not run. The pinned ferx-core moves to
  `e3fb3d1`, which adds the screen (ferx-core #2094): it is on by default, so
  fits whose cold inner solves find a distant lower mode can move.
