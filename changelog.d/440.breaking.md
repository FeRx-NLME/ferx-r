- **`fit$cov_matrix` names every off-diagonal `ROW ~ COL` and every variance
  by its bare name** ([#440](https://github.com/FeRx-NLME/ferx-r/issues/440)).
  An entry of a `block_omega` or `block_kappa` used to be named with a comma
  (`ETA_V,ETA_CL`), its diagonal too (`ETA_CL,ETA_CL`), while a `block_sigma`
  correlation in the same matrix read `ADD_ERR ~ PROP_ERR`. Block covariances
  are now `ETA_V ~ ETA_CL` / `KAPPA_V ~ KAPPA_CL`, block variances the bare
  `ETA_CL` / `KAPPA_CL` as in a diagonal omega, and unnamed kappa variances
  `KAPPA1` in a block too. `fit$cor_matrix` and `fit$cov_fixed` follow.
  Code that indexes these by the comma names must switch to the new ones;
  bundles reloaded with `ferx_load_fit()` take the new names as well.
