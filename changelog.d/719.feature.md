- **Engine features from ferx-core `48546b91..3cd15863`** (#719):

  - **Probit link for `[binary_model]`**
    ([ferx-core #2603](https://github.com/FeRx-NLME/ferx-core/issues/2603)):
    write the predictor as `probit = ...` (or add `link = probit`) for
    `P(DV = 1) = pnorm(lp)`, NONMEM's `P = PHI(LP)`. `pnorm(x)` is a new
    expression function. Both are accepted by a `profile`d theta level block,
    as the logit forms are.
  - **Combined error under log-transform-both-sides**
    ([ferx-core #2729](https://github.com/FeRx-NLME/ferx-core/issues/2729)):
    `log(DV) ~ combined(PROP, ADD)` and `DV ~ log_combined(PROP, ADD)`, NONMEM's
    `W = SQRT(PROP**2 + ADD**2/IPRED**2)`. Per-CMT LTBS is accepted when every
    endpoint is on the log scale. `fit$model_structure$residual` and
    `ferx_model_inspect()` report it as `"combined (log-transformed)"`.
  - **Magnitude expressions on `CMT=N:` lines and inside `if/else` branches of
    `[error_model]`**
    ([ferx-core #2731](https://github.com/FeRx-NLME/ferx-core/issues/2731)),
    e.g. `CMT=1: DV ~ additive(S * (1.0 + (TPF - 1.0) * EARLY))`.
  - **`sin(x)` and `cos(x)` in the model DSL**
    ([ferx-core #2720](https://github.com/FeRx-NLME/ferx-core/issues/2720)),
    in radians, for circadian baselines ported from NONMEM's `SIN`/`COS`.
  - Analytic FOCE/FOCEI fits with time-varying covariates run 10-15% faster,
    with bit-identical results
    ([ferx-core #2558](https://github.com/FeRx-NLME/ferx-core/issues/2558)).
