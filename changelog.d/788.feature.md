- **Markov models fit from R** (#788, part of #789). The package now builds
  ferx-core with its `markov` feature, so a `[markov_model]` block - a
  continuous-time (`type = ctmm`) or discrete-time (`type = dtmm`) Markov
  endpoint on an observed state - fits with `ferx_fit()` as it does from the
  `ferx` command line, instead of being refused with
  `E_BLOCK_FEATURE_DISABLED`. The `ferx` CLI in the Docker images carries the
  feature too.
