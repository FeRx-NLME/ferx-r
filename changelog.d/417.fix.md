- **A `ferx_save_fit()` / `ferx_load_fit()` round trip now gives back
  `sigma`, `cov_matrix`, `sdtab` and the per-subject tables `identical()` to
  the live fit, names and column types included** (#417). The reloaded
  `cov_matrix` (and so `cor_matrix` and `cov_fixed`) had no row or column
  names, since `fit.json` stores none; they are now taken from the engine's
  labels for the bundled model file laid out on the fit's own levels, the
  ones `ferx_fit()` names the matrix with (a model file that no longer hashes
  to `model_hash` leaves it unnamed), so bundles written before this fix - and bundles written by ferx-core
  itself - load named too. `fit$sigma` and `fit$sigma_types` are now named by
  `sigma_names` on the live fit, as a reloaded fit already had them. A column
  of whole numbers or of missing values in `sdtab`, `ebe_etas`, `covtab`,
  `ebe_kappas` or the conditional-distribution table used to load as integer
  or logical, where the live fit has double (`sdtab$N_OBS` always did); it
  now loads as double.
