- **Every model with a `theta NAME[COLS]` level block gets one rank check
  when it is bound, and an aliased model is refused** (#669;
  [ferx-core #1991](https://github.com/FeRx-NLME/ferx-core/issues/1991),
  [#2421](https://github.com/FeRx-NLME/ferx-core/issues/2421),
  [#2375](https://github.com/FeRx-NLME/ferx-core/pull/2375),
  [#2448](https://github.com/FeRx-NLME/ferx-core/pull/2448)). Before, only a
  block that rescued a random effect was checked, so `TVE0 + PLACEBO` under
  `contrast = none` bound with a flat direction. The refusal names a minimal
  set of aliased thetas and blocks, and a contrast that keeps the rank when
  there is one; a block aliased with another theta (`TVB * D2` under
  `contrast = ref`) is refused for that reason rather than with the
  random-effect refusal. Models that bound aliased before, including thetas
  outside every block that duplicate each other in a model with a block, now
  fail to fit. Propensity-score matching on a `[mixture]` model is refused with
  `E_PROPENSITY_INPUT`
  ([ferx-core #2163](https://github.com/FeRx-NLME/ferx-core/issues/2163)).
