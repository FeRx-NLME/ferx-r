- **Engine fixes from ferx-core `aa5f3b6e..86a05bd5`** (#701):

  - **`W_COVARIATE_MISSING` is raised only for a covariate the model reads**
    ([ferx-core #2599](https://github.com/FeRx-NLME/ferx-core/issues/2599)):
    a data column with missing values that no relation reads no longer warns
    that the objective goes `NaN`.
  - **A fit stopped just above the log-packing floor is no longer reported

    ([ferx-core #2629](https://github.com/FeRx-NLME/ferx-core/issues/2629)):
    such a fit, up to 68 OFV above the optimum, was `converged = TRUE`; it is
    now `converged = FALSE`, and its `convergence` warning names the THETA.
  - **Adaptive simulation no longer refuses a run whose first decision comes
    before the subject's first record**
    ([ferx-core #2125](https://github.com/FeRx-NLME/ferx-core/issues/2125)):
    the run failed with "prediction 0 diverges from the frozen-schedule
    replay". The reactive predictions were already right and are unchanged.
