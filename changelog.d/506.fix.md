- **A `ferx_fit(method = ...)` chain sets `interaction` as the same model-file
  `method` line does** (#506): a final `focei` turns it on, a final `foce` off,
  and any other final stage keeps the default (on). The call used to switch it
  off for every chain not ending in `focei`, so `method = "vi"`,
  `c("saem", "imp")` or `c("vi", "laplace")` scored CWRES, SIR and the
  reported objective without interaction where `[fit_options] method = ...`
  used it.
