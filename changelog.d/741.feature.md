- **A `[mixture]` per-class override is reported with its estimate, standard
  error and name** (#741,
  [ferx-core #2833](https://github.com/FeRx-NLME/ferx-core/issues/2833)). An
  `omega(k)` / `sigma(k)` override used to reach R as a bare number in
  `fit$mixture_overrides`, with no SE and no row anywhere. Now:

  - `fit$estimates` has one row per override, after the other parameters,
    named `<base> (class <k>)` (`"ETA_CL (class 2)"`) as in `cov_matrix` and
    `held_at_bound`, with its class in the new `class` column (`NA` on every
    other row). An omega override is the class variance on its base ETA's
    scale; a sigma override is read like its base sigma. `ferx_coef()` and
    `ferx_se()` take the name.
  - `print()` lists them under `MIXTURE  (per-class overrides)`, after SIGMA,
    in the rows of the family they override: `[FIX]` with `SE = ---` for a
    `FIX` override (or a sigma override SAEM held at its initial value),
    `SE = N/A` for one held at a bound. The base parameter keeps its own SE.
  - `ferx_runlog()` lists them in its parameter table too, and now the IOV
    kappas, which it left out. Its gradient section has a scale for those
    coordinates, so a mixture or IOV fit no longer falls back to
    `Gradient (raw - parameter count mismatch)`.
  - New fit fields: `se_mixture_overrides` (parallel to `mixture_overrides`,
    on its scales) and `mixture_override_params` (a data frame: `parameter`,
    `kind`, `index`, `class`, `fixed`). `mixture_overrides` is now named by
    those labels, and `summary()` carries both vectors. All of it survives
    `ferx_save_fit()` / `ferx_load_fit()`. A bundle saved before this release
    keeps its values but names none of them, so it has no rows for them;
    `ferx_covariance()` on it fills `se_mixture_overrides` unnamed. Refit to
    get the rows.
  - Two things existing code may trip over: `fit$estimates` now has rows that
    are not base parameters (filter `is.na(class)`), and a named
    `fit$mixture_overrides` no longer compares equal to a bare number
    (`unname()` it, or index with `[[`).
