  (#509). About 40 keys that worked but were not listed are now described: the
  variational-inference `vi_*` keys and `agq_eval_only` / `n_agq` in new groups,

  `ode_auto_switch`, `ode_stiff_abort_after`, `max_unconverged_frac`,
  `min_obs_for_convergence_check`, `report_final_gradient`, `npde_seed`, and
  the neural-network penalties `nn_l2` / `nn_smooth`. A test compares the list
  with the engine's own, so a new engine key without documentation fails CI.
