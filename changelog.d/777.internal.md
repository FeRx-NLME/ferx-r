- **Model search builds from ferx-core's new `ferx-search` crate** (#777,
  [ferx-core #3185](https://github.com/FeRx-NLME/ferx-core/issues/3185)): the
  glue's `ferx_search_*()` bindings now call `ferx_search::` instead of
  `ferx_tools::`, with no change to any search's behaviour or results.
  `ferx-search` is a third git dependency from the ferx-core repository, pinned
  to the same revision as `ferx-core` and `ferx-tools`; the pin check, the
  sibling build wrapper (which now patches all three and says so in its last
  line), Makevars and Dependabot's ignore list cover it, and the crate list
  lives once, in `tools/ferx-core-lock-lib.sh`.
