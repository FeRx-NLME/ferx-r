- **`ferx_fit(method = "vi")` runs variational inference** (#506): the token used
  to be refused twice, once by R and once by the glue, before it reached the
  engine, so VI could only be selected from a model file. Chains such as
  `c("vi", "laplace")` with `agq_eval_only = TRUE` and `c("vi", "imp")` with
  `imp_eval_only = TRUE` work as they do in `[fit_options]`. `method` tokens are
  now read by ferx-core's own parser, so every method the engine gains is
  accepted without an R-side change.
