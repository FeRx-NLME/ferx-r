- **`ferx_fit(method = "vi")` runs variational inference** (#506). The token
  used to be refused before it reached the engine, which accepted it. Method
  tokens and chains are now read by ferx-core itself, exactly as a
  `[fit_options] method = ...` line is, so a new engine method needs no ferx
  change, and the two finishing chains (`c("vi", "laplace")` with
  `agq_eval_only = TRUE`, `c("vi", "imp")` with `imp_eval_only = TRUE`) work
  from the call.
