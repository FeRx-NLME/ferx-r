- **The package ships its license texts and third-party notices** (#773). The
  ferx package's own code stays MIT, but its compiled library statically links
  ferx-search (model search, now LGPL-3.0-or-later,
  [ferx-core #3183](https://github.com/FeRx-NLME/ferx-core/issues/3183)) and
  NLopt, whose Luksan routines are LGPL-2.1-or-later. The installed package now
  carries `COPYRIGHTS` (which license covers what, and how to rebuild with a
  modified ferx-search), `THIRD-PARTY-NOTICES.txt` (every linked crate's license
  files and the pinned ferx-core commit) and `licenses/` (the LGPL-3.0, GPL-3.0
  and LGPL-2.1 texts): `system.file("COPYRIGHTS", package = "ferx")`.
  `DESCRIPTION` gains a `Copyright` field pointing at them, the vendored
  release tarball is checked to keep every license file, and both Docker images
  install the notices (and `ferx --licenses`) under `/usr/local/share/doc/ferx`;
  the slim image's `org.opencontainers.image.licenses` label now reads
  `MIT AND LGPL-3.0-or-later AND LGPL-2.1-or-later`.
